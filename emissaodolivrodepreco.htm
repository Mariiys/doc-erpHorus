Emissão do Livro de Preço

    

Finalidade :

 

  - Efertivar a geração do relatório referênte ao livro de preço para o gerênciamento de toda a movimentação comercial paga dentro da Unidade Empresarial

 

Síntese :

 

  - A partir da parâmetrização dos campos abaixo o sistema irá emitir relatórios do livro de preço que irá controlar as regulamentações de precificação conforme normas empresariais estabelecidas.

 

Pré-Requisitos :

 

- Região Área de Venda

- Tabela de Preço

- Fabricante

- Gerar Livro Preço

 

Pós-Requisitos :

 

- 

 

Telas:

 

- Botões

 

 

Descrição dos Campos

 

 

Região Venda

Tabela de Preço

Filtre uma região de venda estabelecida para especificação do livro de preço

Filtre uma tabela de preço que irá gerênciar as movimentações do livro de preço dentro dos parâmetros empresariais

Grupo de Preço

Fabricante

Filtre o grupo de preço específico para cada tabela gerênciadora do livro de preço

Filtre o fabricante correspondente ao produto de característico

Preços

Agrupar

Informe se a precificação estabelecida no relatório sera por Livro de Preço ou Tabela de Preço.

Determine a sequência para a emissão do livro de preço como: Idêntico, Preço, Similar.

Data Alteração

Data Específica

Determine a data de alteração para a emissão de relatórios dos livros de preço

Determine uma data para especificar a emissão do livro de preço no relatorio.

Ordenar

Nª de Colunas

Determine se a ordem no livro de preço obedecerá aos sequintes padrões: Código, Descrição, Número Original

Determine o número de colunas para o layout do livro de preço

Tam. Fonte

Tipo

Determine o tamanho da fonte usada para a digitação de dados do livro de preço

Informe neste campo o tipo de livro de preço será emitido, se por: Preço Geral, Preço da Data Específica, Preço do Dia, Preço de Fim de Semana, Preço Venda ( Não sai preço oferta )

Configurações

Quebra por: Grupo, Fabricante, Departamento, Seção, Categoria, Subcategoria.

Determine neste campo as configurações específicas de cada empresa como  Geral e Oferta ou por exemplo algumas já criadas para clientes Potência.

Informe marcando os devidos campos o tipo de quebra que melhor supre as necessidades de visualização do livro de preço pelo usuário.

Nª Original

Somente produtos em oferta

Marque este campo para visualizar o número original no livro de preço

Marque este campo para visualizar somente produtos em oferta no livro de preço

Preço Unitário

Somente produtos com estoque

Marque este campo se desejar visualizar apenas o preço unitário do produto de emissão do livro de preço

Marque este campo para que seja destacado no livro de preço somente produtos com estoque para a visualização do usuário.

Cabeçalho Simplificado

Intercalar a cor das Linhas

Marque este campo para que no cabeçalho do relatório apareca apenas dados restritos ao livro de preço

Determine marcando este campo se poderá ou não intercalar as linhas do livro de preço para efeito de organização.

Validade

 

Determine a validade do livro de preço
