No Sistema Horus, sempre que houver um cancelamento de nota fiscal, o sistema obrigara que esse cancelamento seja confirmado pelo operador do cancelamento, pelo financeiro e pelo responsavel fisico da mercadoria, caso o cancelamento esteja parado em algumas dessas etapas, como o sistema deve proceder ?, escolha aqui qual o procedimento sendo as opcoes: NÃO BLOQUEIO, ou seja, o sistema simplesmente ignorará caso faltem etapas no cancelanento. VENDEDOR, o sistema bloqueia o vendedor que efetuou a venda cancelada, obrigando ele ir atras para resolver a continuidade do cancelamento. UNIDADE EMPRESARIAL, o sistema ficará travado para a Unidade Empresarial, até que se faca todas as etapas do cancelamento.
