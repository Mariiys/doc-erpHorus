Baixar Arquivo da Financeira

    

.Finalidade :

 

- Este campo tem como finalidade, baixar os arquivos enviados pelas financeiras.                                       

 

Síntese :

 

  -  Esta é uma rotina de sincronismo automático         que possibilita ler os arquivos que as financeiras enviam para demosntrar os                  pagamentos efetuados pelas mesmas.        

 

Pré-Requisitos :

 

- Contrato de Financeiras

 

Pós-Requisitos :

 

-

 

Telas:

 

- Botões

 

 

Descrição dos Campos

 

 

Arquivo

Instrução para baixar do arquivo da financeira

Localize no banco de dados o arquivo da financeira a ser baixado.

 

Após selecionar o arquivo a ser baixado, click no botão de

pesquisa ou a tecla de atalho F9. Existem duas abas logo abaixo do caminho do arquivo sendo a primeira aba de registros

Divergentes. Nesta aba de divergentes serão listados todos os registros que não coincidam com a informação registrada no Horus previamente, exemplo:

-Valor líquido a receber menor que o registrado
oBaixa Parcial?
oResgitra como Juros Pagos?
-Valor líquido maior que o registrado

o        Registra como Juros Recebidos?

Para confirmar as baixas tanto as consistentes quanto as divergentes resolvidas, clique no botão de confirmar ou F3.
