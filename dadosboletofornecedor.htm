Dados Boleto Fornecedor

    

Finalidade :

 

- Fornecer ao usuário dados do boleto para viabilizar e agilizar a tranzação.

 

Síntese :

 

  -  Este campo tem como finalidade estabelecer parâmetros para a visualização dos dados pertinentes a negociação desejada.

 

Pré-Requisitos :

 

- Lançar Nota Fiscal

 

Pós-Requisitos :

 

-  Remessa Boleto Bancário
