Empréstimo Financeiro

    

Finalidade :

 

   - Registrar um empréstimo financeiro.

 

Síntese :

 

    - Uma opção para captação financeira é o empréstimo bancário. Para disponibilizar o valor do empréstimo no saldo da conta  corrente é necessário registrar o empréstimo.
