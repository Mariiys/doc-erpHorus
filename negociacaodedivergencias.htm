Negociação de Divergências

    

Finalidade :

 

   - Cadastrar uma negociação de alguma divergência.

 

Síntese :

 

   - Esta rotina foi desenvolvida para contemplar inconsistências e divergências de processos onde se apura como responsável um funcionário e se negocia esta divergência para que o funcionário possa arcar com o prejuízo levantado. Algum responsável negocia com o funcionário relativo a divergência como ele poderia pagar pelo prejuízo, e esta negociação vai para aprovação de um superior.
