Liberação de Pedido de Compra
Previous  Top  Next

Finalidade :

- Liberar o( os ) pedido de compra para a viabilização das emissões das respectivas notas.         

Síntese :

- Este campo tem finalidade específica de liberação dos pedidos cujo status se enconta "a liberar" para a manutenção dos pedidos de compra e controle cadastral do comprador.

Pré-Requisitos :

- Todos os pedidos de compra não costem como liberados
   
Pós-Requisitos :

- Todos os Pedidos de Compra
