Tabela de Preço

    

Finalidade :

 

  - Tem como finalidade gerênciar toda a precificação de produtos comercializados pela Unidade Empresarial em determinada vigência.

 

Síntese :

 

  - Este campo possibilitará ao usuário efetivar tabela(s) de preço conforme sua respectiva região, portanto a parâmetrização destes campos são de importância ímpar para manutenção operacional de todo o sistema de finanças dentro da Unidade Empresarial.

 

Pré-Requisitos :

 

- Região Área de Venda

 

Pós-Requisitos :

 

-  Todos os campos que necessitarem de precificação

 

Telas:

 

- Botões
