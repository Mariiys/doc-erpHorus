Montar Borderô a Pagar

    

Finalidade :

 

  - Montar um borderô a pagar.

 

Síntese :

 

  - O borderô a pagar é um agrupamento de títulos a pagar que tem uma característica em comum, que é a data prevista para pagamento. Nesta rotina seleciona-se os títulos a serem incluidos no borderô através dos filtros de pesquisa e determinando uma data prevista para pagamento. Existe ainda a rotina para a liberação deste borderô.
