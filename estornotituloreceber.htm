Estorno de Titulo

    
Finalidade :
 
- Estornar o recebimento de um título                                           

 

Síntese :

 

  - É possível estornar a baixa de um ou mais títulos, voltando o mesmo a estado de aberto, sem data de baixa, basta selecionar o     título baixado a ser extornado nesta tela.

 

Pré-Requisitos :

 

- Unidade Empresarial ( parceiro ),

- Tipo Documento

 

Pós-Requisitos :

 

-  Acerto de Cargas

- 

 

Telas:

 

- Botões

 

 

Descrição dos Campos

 

 

CPF/CGC

Código

Selecione títulos pelo código do cliente.

Cliente

Tipo Documento

Selecione títulos já recebidos pelo nome do cliente.

Selecione títulos já recebidos pelo CPF ou CGC do cliente.

Fatura

Parcela

Selecione títulos já recebidos pelo número da Fatura.

Selecione títulos já recebidos pelo número da parcela do título.

Período de Baixa

 

Selecione títulos já recebidos pelo intervalo de baixa.
