Preço de Terceiro

    

Finalidade :

 

  - Estabelecer parâmetros necessários para precificação dos produtos terceirizados

 

Síntese :

 

  - Neste campo o usuário poderá através dos parâmetros determinados gerênciar as movimentações sobre os preços de terceiros

 

Pré-Requisitos :

 

- Etapa de Produção

- Unidade Empresarial ( parceiro )

Parceiro
