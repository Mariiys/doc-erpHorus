Atribuição de Responsabilidade

    

Finalidade :

 

- Tem por finalidade atribuir devidas responsabilidades ao usuário.

 

Síntese :

 

  -  A parâmetrização deste campo irá gerênciar a responsabilidades do usuário dentro da Unidade Empresarial

     assim como mudar determinadas funções e documentos.

 

Pré-Requisitos :

 

- Unidade empresarial( parceiro )

- Tipo Documento   

 

Pós-Requisitos :

 

-

 

Telas:

 

- Botões

 

 

Descrição dos Campos

 

 

Data de Vencimento

Listar todas as Unidades Empresariais

Informe uma data  de período para a atribuiçaõ.

Informe se irá listar as Unidades Empresariais, denominando este campo a responsabilidade será abrangente a todas as Unidades.

Listar Somente Títulos Sem Responsável

Responsável

Informe se irá listar somente títulos sem responsável, este campo restringirá o usuário apenas a títulos.

Informe o responsável para parâmetrização.

Cidade

Vendedor

Informe a cidade pertinente à negociação

Informe o vendedor para a negociação, este vendedor pode ou não estar amarrado ao cliente.

Cliente

Atribuir Responsabilidade para:

Informe o cliente para a tranzação.

Marque  para qual área sera atribuída a responsabilidade.

Novo Responsável

Imprime Títulos Selecionados

Se for o caso de criação de um novo responsável ele irá aperecer neste campo.

Marque este campo para imprimir títulos selecionados.

Imprime Lista de Cobrança

Impressão Matricial.

Marque este campo para listar as cobranças.

Informe se a impressão será matricial.
