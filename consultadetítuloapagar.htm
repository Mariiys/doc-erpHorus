Consulta de Título a Pagar

    

Finalidade :

 

- Campo informativo para títulos a pagar.

 

Síntese :

 

  - Este campo tem como função visualizar os títulos a pagar tornando assim mais rápido e seguro o pagamento dos títulos.

 

Pré-Requisitos :

 

-  Unidade Empresarial ( parceiro ),

-  Tipo Documento,

 

Pós-Requisitos :

 

- 

 

Telas:

 

- Botões

 

 

Descrição dos Campos

 

Unidade Empresarial

Vencimento Inicial / Vencimento Final

Informe a Unidade Empresarial cadastrada para esta visualização.

Informe o vencimento inicial e vencimento final do título para  controle de datas de pagamento.

Parceiros

Cnpj/Cpf

Informe o código do parceiro correspondente ao título a ser consultado

Opção de busca do parceiro pelo: Cnpj/Cpf

Nome

Nome Fantasia

Informe o nome do parceiro, se caso corretamente parâmetrizado ao informar o código ou o Cnpj/Cpf automaticamente aparecerá o nome.

Informe o nome fantasia , no caso de pessoa física

Tipo Documento

Portador

Informe o tipo de documento usado na tranzação

Informe o nome do portador do documento

Número

Valor do Título

Informe o número do documento

Informe o valor do título

Posição dos Títulos

Outros Filtros

Informe a posição dos títulos, neste campo o usuário determinará o status do título para pagamento.
