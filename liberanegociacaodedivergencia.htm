Liberação de Negociação de Divergências

    

Finalidade :

 

     - Liberar ou recusar uma liberação e gerar os vales para o funcionário.

 

Síntese :

 

    - Esta é a rotina de aprovação ou recusa de uma negociação proposta. Um funcionário com alçada para tal, vai analisar a proposta de negociação e decidir se ela é viável para a empresa ou não. É possível ainda que este funcionário   "liberador" cadastre o motivo da liberação ou recusa. Para efetivação total da rotina de Liberação de Negociação é necessário  gerar o vale para o funcionário, só então a rotina está concluída
