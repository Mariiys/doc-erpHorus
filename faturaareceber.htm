Fatura a Receber

    

Finalidade :

 

- Cadastrar uma fatura a receber como: Aluguel, etc.

 

Síntese :

 

- Em geral, as receitas de uma empresa provém das vendas, no entanto podem ocorrer outros tipos de receitas que não tenham as  mesmas características de produtos, como por exemplo, uma receita de aluguel de um galpão da empresa.Para registrar esse tipo de receita, ultilizamos a rotina de faturas a receber.

 

Pré-Requisitos :

 

-

- Tipo Documento,

- Moeda e Indexadores

 

Pós-Requisitos :

 

-

 

Telas:

 

- Botões

 

 

Descrição dos Campos

 

 

Cliente

Cnpj/Cpf

Selecionar um Parceiro pelo Nome.

Selecionar um Parceiro pelo CNPJ ou CPF..

Tipo de documento

Número

Selecione um tipo de documento para a fatura.

Digitar um número para a fatura.

Posição

Observação para movimentação de exclusão ou recuperação

Este campo informa se a fatura está ativa ou inativa para recebimento.

Redija as obsevações necessárias para informar ao usuário qual  tipo de movimentação cabe para esta operação.

Condição de pagamento

Data emissão

Selecionar uma Condição de Pagamento para a Fatura.

Digite a data de emissão da Fatura.

 

Moeda

Valor

Selecionar uma moeda para fatura.

Digite o valor da fatura a receber.

Tipo de vencimento

Obsevação

Selecionar um dos tipos de vencimento constantes nas opções deste campo.

Digitar alguma observação inerente à fatura.

Vendedor

Banco

Selecione um vendedor.

Selecione um banco.

Agência

Conta

Selecione uma Agência Bancária.

Selecione uma Conta Corrente.

Carteira

Gera parcela

Indique a carteira já pre-estabelecida, para forma de cobrança.

Selecione este campo se você optar por gerar parcela na fatura a receber.

Deleta parcela

 

Caso não vai mais efetuar a tranzação parcelada, exclua neste campo.

 

 

 

Titulo

Parcela

O título gerado irá aparecer neste campo, confira com o título parâmetrizado.

O número de parcelas destacado aparecerá neste campo confira com o número de parcelas parâmetrizadas.

Data de Vencimento

Data do Desconto

Informe a data de vencimento do título.

Designe uma data limite para desconto caso haja pagamento antecipado.

Observação

 

Anote aqui observações pertinente à negociação.
