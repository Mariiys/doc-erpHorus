Parâmetros de Cliente

    

Finalidade :

 

  - Este parametro é obrigatorio para cada um dos clientes. A finalidade é identificar as individualidades do cliente a nivel de tratamento perante a area Comercial

 

Síntese :

 

  - Além da parâmetrização no cadastro de parceiro ( cliente ) deverá ser neste campo que se estabelecerá o vículo entre cliente e empresa seguindo as características próprioas de cada tela.

 

Pré-Requisitos :

 

- Unidade Empresarial ( parceiro )

Telas:

Descrição dos Campos

 

 

Cliente

Região Preço de Venda

Selecionar o cliente desejado, ou atraves do codigo (CNPJ / CPF) ou pela Razao social no campo ao lado. Ele deve estar previamente cadastrado na tela e indicado como CLIENTE.

Selecionar qual a regiao de preco de venda que esse cliente estará subordinado no ato da venda. Essa informacao é obrigatoria.

 

Banco p/ Emissão Boleto/ Agência/ Conta Corrente/ Carteira

Transportadora Padrão

Selecionar aqui esse conjunto de informacoes que irao identificar qual o boleto bancario que será utilizado na emissao da cobranca, caso seja utilizado o padrao especificado na tela Parametro de Venda, deixar esses campos em branco.

Selecionar aqui uma transportadora (ou pelo numero ou pela Razao social, caso o cliente especifique uma determinada transportadora de forma obrigatoria para entrega das mercadorias.

UNEM p/ Faturamento Força Vendas

Determine em quantos dias o banco enviará os títulos para cartório.

Dados Suframa/Código Data Validade

Desconto Financeiro

Caso o cliente pertenca a categoria de beneficios do Suframa, informar aqui a data de validade para ser impresso na Nota.

Caso o cliente possua um percentual fixo de desconto  financeiro para ser utilizado em todas as compras, informe aqui o percentual. Esclarecendo que o valor da Nota Fiscal será impresso de forma Bruta, constando esse desconto só na cobranca do titulo.

Tipo de Frete/ CIF  FOB

Tipo de Cliente/ Público Privado

Marque o campo indicando se esse cliente trabalha com cobranca de frete CIF ou FOB

Marque o campo indicando se esse cliente pertence ao setor Publico ou Privado.

Ignora Vencimento para Desconto Financeiro?

Entrega Paletizada?

Determine nos parâmetros de cliente se o sistema irá ignorar os vencimentos para atribuir desconto financeiro

 

Marque o campo indicando se esse cliente possui estrutura para receber mercadorias de forma Paletizada. Essa informacao só tem sentido, caso a Empresa esteja trabalhando com o Modulo LOGISTICA.

Contribuinte?

Inscrição Rudimentar?

Informe ao sistema se o cliente é contribuinte para gerar informações no módulo fiscal

Marque o campo indicando caso esse cliente seja enquadrado pela secretaria da Fazenda como RUDIMENTAR, ou seja, uma empresa com CPF. Exemplo: Fazenda Agropecuaria, Feirante, etc.

Roteirização de Entrega/ Ordem de Entrega

Roteirização de Vendas/ Sequência de Visita Dia de Visita  Descrição

Caso a empresa trabalhe com o metodo de Roteirizacao de entrega, informar neste campo a ordem de entrega na rota.

Caso a empresa trabalhe com o metodo de Roteirizacao de Venda, informar neste campo a sequencia de Visita do representante a esse cliente..

Marcar esse campo, caso queira que toda vez que for fazer um pedido de venda o sistema traga automaticamente esta tabela. Condição de Pagamento

Selecionar uma condicao de pagamento pelo seu codigo, ou pelo proximo campo por nome que deverá estar previamente cadastrada  na tela Condicoes de Pagamento

Após a selecao, o sistema mostra a quantidade de parcelas que será utilizada nesta condicao.

 

Prazo Médio

Condição de Pagamento Padrão?

Após a selecao, o sistema mostra a quantidade de dias de prazo medio que esta condicao tem.

 

Marcar esse campo, caso queira que toda vez que for fazer um pedido de venda o sistema traga automaticamente esta condicao de pagamento. Lembrando que so poderemos utilizar uma condicao como padrao de cada vez, para trocar, devemos entrar na condicao que tem essa indicacao, retira-la e depois marcar na condicao desejada.
