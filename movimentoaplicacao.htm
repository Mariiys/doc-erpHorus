Movimento de Aplicação Financeira

    

Finalidade :

 

   - Efetivar a aplicação financeira já simulada e liberada ou recusar a mesma.

 

Síntese :

 

   - Após uma simulação de aplicação ter sido aprovada, é necessário que ela seja efetivada no Horus, o que pode ser feito pelo mesmo usuário ou por outro usuário de alçada diferente. As aplicações com status de "Aprovado" são as que podem ser efetivadas, como padrão esta opção já vem marcada nesta rotina, demonstrando na grid "Aplicações" todas as aplicações aprovadas. Para efetivar as mesmas, basta clicar em uma delas e escolher a origem do recurso, que poderá provir de um caixa, para isso marque a opção "Capta Recurso do Caixa" e selecione um caixa para prover os recursos, se for de uma conta corrente selecione uma conta corrente para a origem dos recursos.Escolha também o destino da aplicação.
