Suspensão de Títulos a Pagar

    

Finalidade :

 

- Tem por finalidade tirar de negociação títulos que estão para pagar.

 

Síntese :

 

  -  A parâmetrização deste campo permite a suspensão de títulos que estejam sendo negociados, previamente.

 

Pré-Requisitos :

 

-  Unidade Empresarial ( parceiro )

-  Moeda e Indexadores

-  Tipo Documento

 

Pós-Requisitos :

 

-  Pagamento de Títulos

 

Telas:

 

- Botões

 

 

Descrição dos Campos

 

 

Unidade Empresarial

Parceiro

Informe a unidade empresarial pertinente à movimentação

Informe o parceiro previamente cadastrado

Cnpj/Cpf

Nome

Busque o parceiro pelo Cnpj/Cpf

Informe o nome do parceiro para esta movimentação

Tipo Documento

Portador

Informe o tipo de documento que foi usado na parâmetrização de Pagamento de Título, deverá ser o mesmo  também para a suspensão.

Informe o portador dos títulos.

Número

Nosso Número

Informe o número do título a ser suspenso

Se houver ultilizado este campo na parâmetrização do Pagamento de Títulos deverá ser informado o mesmo número neste campo

Valor do Título

Parcela

Informe o valor do título

Campo informativo do número de parcelas

Vencimento Inicial

Status do Título Aberto / Suspenso

Informe o período de vencimento do título a pagar

Informe o status do título, é neste campo que será determinada a suspensão do título.

Observação

 

Redija neste campo informações pertinentes à movimentação.
