Administração de Preços

    

Finalidade :

 

  - Reponsável por toda a movimentação de precificação da Unidade Empresarial

 

Síntese :

 

  - Este campo é o gerênciador dos preços estabelecidos através de parâmetros onde o usuário poderá manter a manutenção periódicas de  todas as relações de precificação que exige a Unidade Empresarial

 

Pré-Requisitos :

 

- Unidade Empresarial ( parceiro )

- Produto

 

Pós-Requisitos :

 

-  Vendas

 

Telas:

 

- Botões
