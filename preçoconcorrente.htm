Finalidade :

Síntese :

-Local reservado para registros dos preços praticados pelos concorrentes diretos em determinadas regiões. Essa informação coletada, aparecerá na tela de pedido de compra (com o preço médio das coletas) para auxiliar o comprador.Os dados aqui serão oriundos de uma planilha preenchida manualmente, pois caso seja transmitida pelo sistema Móbile essas informações entrarão no sistema automaticamente.
