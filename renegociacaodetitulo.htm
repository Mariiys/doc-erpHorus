Renegociação de Titulo

    

Finalidade:

 

- Tem como finalidade viabilizar negociações de títulos inadimplentes.

 

Síntese :

 

   - Este campo é determinante para rever títulos vencidos que o cliente queira renegociar com a Unidade Empresarial.

 

Pré-Requisitos :

 

-  Tipo Documento,

- Unidade Empresarial ( parceiro )

 

Pós-Requisitos :

 

- Recebimento de Títulos

 

Telas:

 

- Botões
