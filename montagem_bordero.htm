Montagem Borderô a Receber

    

Finalidade :

 

   - Montar um borderô a receber.

 

Síntese :

 

    - Este parâmetro determina um agrupamento de títulos a receber tem uma característica em comum que é a data prevista para recebimento. Nesta rotina seleciona-se os títulos a serem incluídos no borderô através dos filtros de pesquisa e determinando uma data prevista para recebê-los.
