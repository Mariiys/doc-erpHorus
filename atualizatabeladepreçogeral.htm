Atualiza Tabela de Preço

    

Finalidade :

 

  - Efetivar as atualizações necessárias nas tabelas de preço conforme parâmetros empresariais.

 

Síntese :

 

  - Este campo tem finalidade específica de estabelecer parâmetros necessários para a atualização e manutenção das tabelas de preços relaçionadas com cada Unidade Empresarial.
